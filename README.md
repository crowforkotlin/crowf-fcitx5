# crowf-fcitx5

A rounded-corner theme for [fcitx5](https://fcitx-im.org/) with Material You
dynamic colours generated by [matugen](https://github.com/InioX/matugen).

Two goals, in order:

1. **Look identical in every client.** Most fcitx5 themes only get rounded
   corners in apps that draw the candidate window themselves through fcitx5's
   own UI. Applications using the Qt frontend (WeChat, some Qt apps) draw their
   own candidate window and can only decode PNG — with an SVG-only theme they
   silently fall back to a flat rectangle.
2. **Follow your wallpaper.** Ship a matugen template, so the theme recolours
   together with the rest of the desktop instead of being a fixed palette.

## install

```bash
git clone https://github.com/crowf/crowf-fcitx5.git
cd crowf-fcitx5
./install.sh                            # install the dark variant as "crowf"
./install.sh --light                    # or the light variant
./tools/register-matugen.sh             # hook into an existing matugen setup
```

`install.sh --matugen` also exists, but it appends to `~/.config/matugen/config.toml`
blindly. If you already have a matugen setup (dotfiles, DankMaterialShell,
anything that regenerates on wallpaper change), prefer
`tools/register-matugen.sh` — it wraps its block in markers so `--uninstall`
can remove it cleanly, and it will not duplicate an existing registration.

Then restart fcitx5 and select the theme:

```bash
fcitx5 -r -d
```

```ini
# ~/.config/fcitx5/conf/classicui.conf
Theme=crowf
```

Dependencies: `fcitx5`, `librsvg` (for `rsvg-convert`), and `matugen` only if
you want dynamic colours.

## dynamic colours with matugen

`install.sh --matugen` appends three template entries to
`~/.config/matugen/config.toml`:

```toml
[templates.crowf_theme]
input_path = '~/.config/matugen/templates/crowf/theme.conf'
output_path = '~/.local/share/fcitx5/themes/crowf/theme.conf'

[templates.crowf_panel]
input_path = '~/.config/matugen/templates/crowf/panel.svg'
output_path = '~/.local/share/fcitx5/themes/crowf/panel.svg'
post_hook = 'rsvg-convert -w 48 -h 48 ~/.local/share/fcitx5/themes/crowf/panel.svg -o ~/.local/share/fcitx5/themes/crowf/panel.png'

[templates.crowf_highlight]
input_path = '~/.config/matugen/templates/crowf/highlight.svg'
output_path = '~/.local/share/fcitx5/themes/crowf/highlight.svg'
post_hook = 'rsvg-convert -w 48 -h 48 ~/.local/share/fcitx5/themes/crowf/highlight.svg -o ~/.local/share/fcitx5/themes/crowf/highlight.png'
```

Regenerate at any time:

```bash
matugen image /path/to/wallpaper.jpg -m dark     # or -m light
```

### standing alone vs. riding an existing setup

Two entry points, pick one:

| | when | what it does |
| --- | --- | --- |
| `tools/generate.sh IMAGE [--mode light]` | no matugen setup yet | builds a throwaway config, writes the theme once |
| `tools/register-matugen.sh` | you already have matugen drivers (dotfiles, DMS, wallpaper daemon) | appends marked template entries so **your existing trigger** recolours fcitx5 too |

The second one is what you want if switching wallpaper or theme already
recolours the rest of your desktop. Verified with DankMaterialShell: after
registering, `dms ipc call theme toggle` regenerates
`~/.local/share/fcitx5/themes/crowf/` along with every other template.

Note that fcitx5 reads the theme from `classicui.conf`, and DMS rewrites the
`Theme=` key when it manages that file. If your theme keeps reverting, point
`Theme=crowf` at it again after a DMS theme change, or disable DMS's own fcitx5
template (`--skip-templates dmsfcitx5,dmsfcitx5panel,dmsfcitx5highlight`).

### what matugen integration needs from you

If you want to build your own theme on this base, the template contract is:

- **Placeholders are `{{colors.<name>.default.hex}}`.** matugen resolves them
  from the palette it just generated. The `default` variant always follows the
  mode (`-m dark` / `-m light`), so a single template serves both themes — run
  matugen twice and point the two output paths at your dark and light theme
  directories.
- **`post_hook` is a plain shell string**, not a table. It runs after each file
  is written, which is how the PNG gets produced next to the SVG.
- **Literal `{{` in comments will break the run.** matugen parses the whole
  file, so never write `{{...}}` in a comment describing placeholders.

The relevant colour choices are documented inline in
`matugen/templates/crowf/theme.conf`. The two that are easy to get wrong:

| Setting | Use | Why |
| --- | --- | --- |
| `NormalColor` | `on_surface` | must contrast with the panel fill |
| `HighlightCandidateColor` | `on_primary_fixed` | the pill is `primary_fixed_dim`, and Material You's `*_fixed*` colours are identical in light and dark schemes — `on_primary_fixed` is the only foreground that stays readable in both |

A `dotfiles`-style setup that also drives the desktop (as
[DankMaterialShell](https://github.com/AvengeMedia/DankMaterialShell) does)
works fine: matugen runs once and every registered template, including this one,
regenerates.

## design constraints (read before editing the SVGs)

The input panel is drawn with 3×3 nine-slice scaling. The corners are copied
and the edges are stretched to whatever size the panel needs, so:

- **The centre cell must be non-empty.** `image_size - Margin > 0`. With a
  48×48 canvas and `Margin=20`, the centre is 8×8. If you raise `Margin` to 24
  the centre becomes 0 and the panel renders hollow — the desktop shows
  straight through the middle.
- **Each edge cell must be a straight run.** If a `Margin` cuts into the rounded
  corner, that curvature gets stretched along the panel and the corners smear.
- **PNG is the shipping format,** not SVG. fcitx5's own renderer and the GTK
  panel decode SVG, but the Qt candidate window (WeChat) has no SVG decoder and
  falls back to a flat fill. PNG is decoded natively by all three.

Validate after any change:

```bash
python3 tools/render.py --static   # re-render the shipped PNGs
python3 tools/render.py --check    # nine-slice geometry + centre cell
```

## layout

```
install.sh                      one-shot installer
src/panels/panel.svg            editable panel source (48x48, r=12)
src/highlights/highlight.svg    editable pill source (48x48, r=10)
themes/crowf-dark/              shipped static theme
themes/crowf-light/
matugen/templates/crowf/        matugen template (theme.conf + both SVGs)
tools/render.py                 render + validate static themes
tools/check-geometry.py         nine-slice validator (usable standalone)
tools/generate.sh               standalone matugen run (no existing setup)
tools/register-matugen.sh       hook into an existing matugen config
packaging/PKGBUILD              AUR package
```
